# PiSecOps: Mumbai Open World — Controls & Keybindings

## On-Foot Controls (PiSecOps)

| Input | Action |
|-------|--------|
| `W` / `Up Arrow` | Move Forward |
| `S` / `Down Arrow` | Move Backward |
| `A` / `Left Arrow` | Move / Strafe Left |
| `D` / `Right Arrow` | Move / Strafe Right |
| `Shift` (Hold) | Sprint |
| `Space` | Jump |
| `C` | Crouch / Stealth Mode |
| `F` or `E` | Enter Nearby Vehicle / Interact with POIs (Chai tapri, Hacker Terminal) |
| `Mouse Move` | Look Around / Rotate Third-Person Follow Camera |
| `Mouse Left Click` / Pointer Lock | Lock cursor for immersive 360-degree free camera |
| `M` or `Tab` | Open Cyber Smartphone / Hacker Terminal |
| `Esc` | Pause Menu / Release Mouse Pointer Lock |

---

## Driving Controls (Vehicles)

| Input | Action |
|-------|--------|
| `W` / `Up Arrow` | Accelerate (Gas) |
| `S` / `Down Arrow` | Brake / Reverse |
| `A` / `Left Arrow` | Steer Left |
| `D` / `Right Arrow` | Steer Right |
| `Space` | Handbrake / Drift |
| `F` or `E` | Exit Vehicle |
| `H` | Honk Horn (Custom Mumbai taxi twin-tone horn) |
| `L` | Toggle Headlights & Dashboard Illumination |
| `C` | Change Vehicle Camera Angle (Close, Far, Bumper) |

---

## Cyber Smartphone & Terminal Controls

| Input | Action |
|-------|--------|
| `M` or `Tab` | Toggle Smartphone Rig on/off |
| `1` | Open GPS City Map & Navigation Waypoint |
| `2` | Open Hacker Terminal (Run WiFi / RFID / Bluetooth sniffer) |
| `3` | Police Radio Scanner (Monitor active wanted level & pursuit vectors) |
| `4` | Contacts & Mission Intel Log |
