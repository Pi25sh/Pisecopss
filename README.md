# PiSecOps: Mumbai Open World 3D (GTA Mumbai)

An open-world 3D action sandbox set across the photorealistic 594,244 buildings of Greater Mumbai, featuring the Gateway of India, The Taj Mahal Palace Hotel, Apollo Bunder waterfront, dynamic city-wide road traffic, third-person walking/sprinting controls, playable vehicles (Kaali-Peeli Santro Taxi, BEST Bus, Bajaj Auto-Rickshaw, Police SUV, Street Motorcycle), and animated Mumbai street NPCs.

---

## 🚀 Quick Start (One-Click)

1. Double-click `START_GAME.bat` (or open a terminal and run `npm run dev` or `npx vite`).
2. Open your browser to: **`http://localhost:5173/mumbai-3d/`**
3. The game starts instantly at Apollo Bunder facing the Gateway of India arches!

---

## 🎮 Controls

### Character Controls:
- **`W / A / S / D`** or **`Arrow Keys`**: Move character (Walk / Run)
- **`Shift`**: Sprint (uses stamina meter)
- **`Mouse Drag`**: Rotate 360° third-person camera
- **`Scroll Wheel`**: Zoom camera in / out
- **`Spacebar`**: Jump
- **`E`**: Enter / Drive nearest vehicle (or hijack any traffic car on the road!)

### Vehicle Driving Controls:
- **`W / Arrow Up`**: Accelerate
- **`S / Arrow Down`**: Brake / Reverse
- **`A / D`** or **`Left / Right`**: Steer
- **`Spacebar`**: Handbrake / Drift
- **`H`**: Authentic Indian street horn (horn-ok-please!)
- **`E`**: Exit vehicle

---

## 🗺️ Key Features

- **Advanced Proximity Streaming**: Streams 3D buildings and road geometry dynamically within a 650m active player radius. No full-city loading lag! Steady 60-140 FPS!
- **Dynamic Mumbai Traffic**: Kaali-Peeli Santro taxis, red BEST double/single-decker buses, and auto-rickshaws dynamically cruise along streets throughout Mumbai.
- **Any Car is Playable**: Walk up to any car on any road across Greater Mumbai and press **`[E]`** to hijack and drive it.
- **100% Solid Land Placement**: All vehicles, NPCs, vendors, and props are stationed strictly on Apollo Bunder paved roads and the Gateway plaza with seawall protection so nothing falls into the Arabian Sea.
- **Clean Map View**: Place name tags and text labels have been removed from the 3D map for an immersive cinematic open-world experience.
- **Time of Day Slider**: Adjust the bottom slider or click morning, afternoon, sunset, and night for dynamic Mumbai lighting and glowing neon headlights!
